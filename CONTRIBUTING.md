# Contributing to Awesome EVM

Thanks for helping curate this list. The bar for inclusion is intentionally
high so the list stays useful.

## Inclusion criteria

A project belongs in this list if it meets **all** of the following:

1. **Open source.** Code is publicly available under a permissive or
   copyleft license (MIT, Apache-2.0, GPL family, AGPL, BSL, CC0, etc.).
2. **Actively maintained.** Commits in the last 12 months, or a stable
   production deployment that has not required a fix.
3. **EVM-relevant.** Runs on, integrates with, or directly tools an EVM
   chain. Non-EVM-specific projects (general crypto, non-EVM L1s) do not
   belong here unless they have a first-class EVM integration.
4. **Useful beyond a single team.** Has documentation, multiple users,
   or is the reference implementation of a public standard.

## How to add a project

1. Fork this repository.
2. Open `README.md` and add your project to the relevant category, in
   **alphabetical order** within that category.
3. Use the format:
   ```
   - [Project Name](https://github.com/org/repo) — One concise sentence describing what it does, not what it claims to do.
   ```
4. Keep descriptions to one sentence. Lead with the function, not adjectives.
   Avoid marketing language ("revolutionary", "industry-leading", "best",
   "ultimate", etc.).
5. Open a pull request. Include a one-line justification of why the project
   belongs here if it's not obvious.

## How to update or remove a project

If a project has become unmaintained, has been superseded by a successor,
has changed its license, or has been compromised, open a PR that updates or
removes the entry, with a one-line note explaining the change.

## Categories

If you think a category is missing, open an issue first. New categories
should cover at least three distinct projects, otherwise the entry probably
belongs in an adjacent category.

## Code of conduct

Be respectful, focus on the project, not the person. We follow the
[Contributor Covenant](https://www.contributor-covenant.org/).
